## 산술연산자
* 피연산자가 숫자인경우 >> 산술연산자
* `a + b` 더하기 | 두개의 피연산자를 더한다
* `a - b` 뺴기 | 왼쪽의 피연산자에서 오른쪽 피연산자를 뺸다
* **`a * b`** 곱하기 | 두개의 피연산자를 곱한다
* **`a / b`** 나누기 | 왼쪽의 피연산자를 오른쪽 피연산자로 나눈 몫이다
* **`a % b`** 나머지 | 왼쪽의 피연산자를 오른쪽 피연산자로 나눈  나머지이다
* `a ** b` 거듭제곱 | 왼쪽의 피연산자의 오른쪽 피연산자의 값만큼 곱한 값이다
* 계산할 수 없는 경우는  NaN 처리 (ex) 'two' * 2 = NaN
* 더하기 연산자는 피연산자에 따라 문자열이 하나라도 있으면 문자열 결합으로 나타나지만, 뺴기,곱하기,나누기 연산자는 숫자형으로 자동 형변환하여 인식함 
* (ex) '일'+ 1 = 연결연산자/문자열결합 / '1' + 1 = 숫자형으로 형변환, 2

### 참(Truthy)으로 인식하는 데이터 종류
* 위 거짓이 아닌 나머지 모든 데이터
* `[]`,`{}` 빈배열, 빈객체는 참으로 인식함, (내장함수때문)
### 논리 데이터구분하는 내장함수
* `Boolean(확인데이터)`
* `console.log(Boolean(null));` null 데이터의 논리종류를 콘솔에 실행
### 비교연산자 
* 데이터 2개 이상을 비교하여 논리결과 (참,거짓)로 출력하는 연산자
* `==`, `===` : 일치연산, = 피연산자가 같으면 참, 다르면 거짓
* `!=`,`!==` : 부등연산, = 피연산자가 다르면 참, 같으면 거짓
* `>`, `<` : 작다, 크다 = 피연산자가 작거나 크면 참
* `>=`, `<==` : 작거나 같다, 크거나 같다 = 피연산자가 작거나 같으면 참
### 조건식
* `if(조건식){조건식이 참일때 실행되는 위치}`
* `else{위 조건식이 거짓일때 실핼되는 위치}`
* `{}` 안 실행 명령이 1줄이면 중괄호 생략가능, 2줄이상이면 중괄호 필수
* `if(){}`, `if(){}`
 * if가 새로 써있다면 기존 조건식과는 별개의 조건식으로 구분함
